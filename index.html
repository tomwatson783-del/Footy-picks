Model Test

Compares all 12 window-and-weight combinations on a later chronological test period. Each match is predicted using only results that happened before it.

How to read the test: higher outcome accuracy is better; lower Brier score and log loss are better. The test period is used to compare candidates, so its winner is not proof of future performance.

The test optimises on earlier matches, then compares current and recommended settings on later unseen fixtures. Recommendations are never applied automatically.

Prediction Settings

How should the model be selected?

Auto uses Brier score, which measures the accuracy of all three outcome probabilities. If there are too few eligible test matches, Auto falls back to your manual model.

Outcome prediction thresholds

Minimum expected-goals advantage needed to predict a winner; otherwise the pick is a draw. The predicted score always agrees with the chosen outcome.

Run Model Test to compare your settings with a recommendation.

Confidence scoring — active settings

Four integer maxima must total exactly 10. Risk penalties and sample caps apply after points are earned.

Goal-gap caps and low-history thresholds can be tested in the separate Calibrator and applied explicitly.

Run Model Test to compare confidence settings.
