Understanding the rankings

🟢Stronger signal: several available indicators support the scenario, such as a strong pre-match forecast plus a close score and positive live pressure.
🟠Watchlist: some evidence supports the scenario, but there are meaningful unknowns or counter-signals.
🔴Weak or limited: available evidence is not convincing, or important live data is missing.

The ranking is a heuristic, not a statistically calibrated in-play probability. The existing model is trained on pre-match team results, not historical in-play situations. Odds, red cards and detailed match stats are only used when a source actually provides them.

Model Test

Compares four recent-form models on a later chronological test period. Each match is predicted using only results that happened before it.

How to read the test: higher outcome accuracy is better; lower Brier score and log loss are better. The test period is used to compare candidates, so its winner is not proof of future performance.
